# Webサイト チーム制作

## 概要

約2か月間、10名のチームでWebサイトを制作しました。

私は4名で構成されたコーディングチームの**コーディングリーダー**を担当しました。デザインカンプを基に実装単位への分割、メンバーへの担当割り振り、命名・ファイル構成ルールの策定、成果物の確認・統合、技術相談への対応、公開環境へのアップロードなどを担当しました。

自身も実装を担当し、JavaScriptによる動的な処理が必要なセクションを中心に、HTML・CSS・JavaScriptまで一貫して制作しました。

## 制作期間

約2か月

## チーム構成

-   ディレクター：1名
    -   サイト全体の企画・方向性、サーバー関連などを担当
-   副ディレクター：1名
    -   デザイン・コーディング双方を補助
-   デザインチーム：4名
    -   デザインカンプまでを担当
    -   デザインリーダー：1名
-   コーディングチーム：4名
    -   デザインカンプを基にした実装からサーバー公開までを担当
    -   **コーディングリーダー：1名（本人）**

## 担当範囲

### コーディングリーダー

デザインカンプを確認したうえでサイトを実装単位に分け、各メンバーの習熟度や担当可能な範囲を考慮しながら担当を割り振りました。

例として、ヘッダー・フッター、各セクションなどをメンバーごとに分担し、自身はJavaScriptによる動的な実装が必要な領域を中心に担当しました。

また、複数人での制作時にファイルやコードが混乱しないよう、以下のルールを決定・共有しました。

-   class名
-   画像ファイル名
-   フォルダ名
-   フォルダ構成

制作中はメンバーからの技術的な相談に対応し、各担当セクションを組み合わせた際にレイアウトや実装上のズレが発生した場合には、必要に応じて調整・修正を行いました。

デザインカンプの内容をそのまま実装することが難しい場合には、デザインチーム側と相談し、実装方法やデザイン上の調整について提案を行いました。

### 自身のコーディング

自身が担当したセクションについては、デザインカンプを基にHTML・CSS・JavaScriptを使用して一貫して実装しました。

JavaScriptを必要とする領域を主に担当し、静的なレイアウトだけでなく、ユーザー操作やスクロールに応じて動作する機能も実装しました。

## 主な実装内容

### カルーセル

左右のボタンおよびインジケーターから画像を切り替えられるカルーセルを実装しました。

ユーザーが操作していない場合には、一定時間ごとに自動で画像が切り替わる機能も実装しています。

### 無限ループスライダー

ロゴ一覧を上下2段に配置し、上段は右方向、下段は左方向へ連続して流れる無限横スクロールを実装しました。

### スクロール連動の背景色変更

ページのスクロール位置に応じて、特定のセクションで背景色が切り替わる演出を実装しました。

## JavaScriptの実装について

JavaScriptは制作当時の授業範囲外だったため、Web検索、GeminiなどのAIツール、提供されたベースコードを参考にしながら実装しました。

ベースコードをそのまま使用するのではなく、サイトのデザインや必要な動作に合わせてパラメータなどを調整し、動作確認と修正を繰り返しながら各機能をサイトへ組み込みました。

## 制作時に苦労した点・工夫した点

### デザインカンプの再現

担当セクションでは、デザインカンプを単純に固定値で再現するだけではなく、画面やコンテンツの幅が変化した場合にもレイアウトが不自然にならないよう調整しました。

特に罫線を使用したデザインでは、線同士が完全につながるのではなく意図した隙間が残るようにしながら、幅に応じて自然に調整されるようCSSを調整しました。

### 複数人でのファイル管理

複数人で制作する際のファイル名や構成の不一致を防ぐため、命名規則やフォルダ構成を事前に決めて共有しました。

各メンバーが作成したファイルはDiscordを通して受け取り、内容やファイル構成を確認したうえで統合する運用としました。

サーバーへのアップロードにはFileZillaを使用し、公開環境のファイルを直接操作する担当を限定することで、誤ったファイルの上書きや構成変更などが発生しないよう管理しました。
